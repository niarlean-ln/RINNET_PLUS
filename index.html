RINNET+

Enterprise Infrastructure Management System

Sistem terintegrasi modern untuk pengelolaan infrastruktur server cloud, alokasi jaringan reseller, manajemen SDM operasional, serta pemantauan finansial secara realtime.

Supabase Cloud DB Realtime Sync Role-Based Access End-to-End Encryption Excel Engine Integration
Fitur Utama Sistem
  • Multi-Server Cloud Management: Pencatatan & pengelompokan server berdasarkan cluster wilayah A-Z.
  • Pendaftaran & Stok Voucher: Monitoring stok voucher harian dan bulanan reseller secara akurat dengan filter tanggal.
  • Rekapitulasi SDM & Kasbon: Sistem pencatatan kasbon karyawan terhitung otomatis (2 mingguan & bulanan).
  • Live System Performance & Active Tracker: Pemantauan CPU, Memory, Latensi DB Supabase, serta daftar user/device aktif secara realtime.
Fitur Keamanan Canggih Terbaru
  • End-to-End Encryption (E2EE): Enkripsi AES-GCM 256-bit native browser untuk perlindungan integritas data.
  • Session Inactivity Auto Lockout: Otomatis mengunci dan mengakhiri sesi jika tidak aktif selama 20 menit.
  • Login Brute-Force Protection: Pembatasan percobaan login salah berturut-turut untuk mencegah pembobolan akun.
  • Realtime Active Tracker Log: Pencatatan audit trail aktivitas pengguna lengkap dengan informasi OS, perangkat, dan koordinat.
Spesifikasi Teknologi
Frontend Architecture:HTML5, Bootstrap 5.3 Modern UI, JavaScript ES6+ Async/Await, SweetAlert2 Engine
Backend & Cloud Storage:Supabase PostgreSQL Cloud Realtime Engine
Encryption Standard:Web Crypto API (SubtleCrypto AES-GCM 256-bit E2EE)
System Analytics Engine:Chart.js Dual-Axis Performance Renderer & Active User Heartbeat Tracker
Export & Document Engine:ExcelJS & FileSaver.js Integration
