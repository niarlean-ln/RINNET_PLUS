RINNET+

Enterprise Infrastructure Management System

Sistem terintegrasi modern untuk pengelolaan infrastruktur server cloud, alokasi jaringan reseller, manajemen SDM operasional, serta pemantauan finansial secara realtime.

Supabase Cloud DB Realtime Sync Role-Based Access Excel Engine Integration
Fitur Utama Sistem
  • Multi-Server Cloud Management: Pencatatan & pengelompokan server berdasarkan cluster wilayah A-Z.
  • Pendaftaran & Stok Voucher: Monitoring stok voucher harian dan bulanan reseller secara akurat.
  • Rekapitulasi SDM & Kasbon: Sistem pencatatan kasbon karyawan terhubung ke sumber dana server.
  • Live System Performance: Pemantauan performa CPU, Memory, dan Latensi DB secara langsung.
Teknologi & Spesifikasi
Frontend Framework:HTML5, Bootstrap 5.3, JavaScript ES6+
Backend & Realtime:Supabase PostgreSQL Cloud Services
Visualisasi Analytics:Chart.js Engine
Export Engine:ExcelJS & FileSaver.js Integration
Pengembang Utama:Lean Naddhito
